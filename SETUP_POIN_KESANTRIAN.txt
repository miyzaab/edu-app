❓ BANTUAN:

1. Fitur tidak muncul?
   → Clear browser cache
   → Login ulang
   → Pastikan user memiliki permission 'halaqah'

2. Form tidak bisa submit?
   → Check browser console (F12)
   → Pastikan JavaScript enabled
   → Cek BASE_URL di config/koneksi.php

3. Notifikasi tidak terkirim?
   → Cek tabel notifikasi_ortu di database
   → Pastikan siswa_id valid
   → Cek table users untuk parent link
